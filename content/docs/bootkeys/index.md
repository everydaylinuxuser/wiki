# Boot Menu & BIOS/UEFI Keys by Computer Manufacturer

When performing system maintenance, installing an operating system, or changing hardware settings, knowing the correct function key or shortcut for your specific computer make and model is essential.

Below is a comprehensive quick-reference table covering major computer manufacturers, their specific series/models, and the corresponding keys to access the **Boot Menu** and **BIOS / UEFI Setup**.

## Important Tips & Troubleshooting

1. **Windows Fast Startup Interference:**
Modern Windows operating systems (Windows 10 & 11) use **Fast Startup**, which puts the system into a hybrid hibernation state. This often bypasses keypress detection during boot.
* *Workaround:* Hold down the **Shift** key while clicking **Restart** in the Start Menu to force a full cold reboot.
* *Access via Windows Settings:* Go to `Settings` > `System` > `Recovery` > `Advanced Startup` (click **Restart now**), then navigate to `Troubleshoot` > `Advanced options` > `UEFI Firmware Settings`.


2. **Function Key Lock (Fn Lock):**
On modern laptops, Function keys often default to media controls (brightness, volume). Try holding **Fn + [Key]** (e.g., **Fn + F12** or **Fn + F2**) if pressing the key alone does not register.
3. **Disabled Boot Menu:**
On brands like **Acer**, the F12 Boot Menu is disabled by default in firmware for security. You must enter the BIOS setup first using **F2**, navigate to the **Main** tab, enable **F12 Boot Menu**, and save settings (**F10**).
